CYBERSENTINEL_AUTH_ML — CATALOG
=================================

--> FILES

cybersentinel_auth_ml/
= Contient le pipeline Machine Learning de détection d’anomalies d’authentification.

config.py
= Centralise la configuration PostgreSQL, les paramètres ML, les features et les seuils.

data_loader.py
= Charge, nettoie, valide et prépare les features d’authentification.

database.py
= Crée et gère les connexions PostgreSQL du module ML.

feature_engineering.py
= Fournit l’interface de préparation des features avant le modèle.

main.py
= Point d’entrée du pipeline Machine Learning.

metadata.py
= Ajoute les métadonnées et la traçabilité du modèle aux résultats.

ml_model.py
= Entraîne Isolation Forest et calcule les anomalies d’authentification.

pipeline.py
= Orchestre toutes les étapes du pipeline ML.

reporting.py
= Organise, exporte et résume les résultats Machine Learning.

repository.py
= Lit les features PostgreSQL et réalise l’UPSERT des résultats ML.

risk_engine.py
= Calcule le risque de sécurité, les raisons et les actions recommandées.
