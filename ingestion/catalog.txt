=================================
INGESTION — CATALOG
=================================

1. FILES / FOLDERS

ingestion/
= Gère la validation, la configuration, la traçabilité et le chargement des données vers PostgreSQL Bronze.

config.py
= Centralise la configuration PostgreSQL et les paramètres du processus d’ingestion.

metadata.py
= Calcule l’empreinte SHA-256 des fichiers pour la traçabilité et la déduplication.

postgres_loader.py
= Réalise le chargement principal des fichiers CSV vers les tables Bronze PostgreSQL.

validators.py
= Vérifie la validité technique des fichiers avant leur chargement.

__pycache__/
= Cache Python généré automatiquement.

3. TECHNOLOGIES / TECHNIQUES

Python
= Implémentation du module d’ingestion.

Pandas
= Lecture, préparation et chargement des fichiers CSV.

PostgreSQL
= Stockage des données dans la couche Bronze.

SQLAlchemy
= Connexion, inspection et exécution des opérations PostgreSQL.

psycopg2
= Driver PostgreSQL utilisé par SQLAlchemy.

JSONB
= Stocke les colonnes supplémentaires non modélisées.

python-dotenv
= Charge la configuration depuis le fichier .env.

dataclass
= Structure les configurations et résultats de validation.

SHA-256
= Identifie les fichiers et évite les rechargements.

FILE_TABLE_MAPPING
= Associe chaque fichier source à sa table Bronze.

LEGACY_COLUMN_MAPPING
= Assure la compatibilité avec les anciennes colonnes des collecteurs.

Schema Inspection
= Utilise PostgreSQL comme référence pour les colonnes attendues.

Idempotency
= Évite de charger plusieurs fois le même fichier.

UPSERT
= Met à jour ou crée l’enregistrement d’audit avec ON CONFLICT.

Audit Trail
= Trace chaque chargement dans audit.file_loads.

Transaction
= Regroupe insertion Bronze et audit dans une même transaction.

Chunk / Batch Loading
= Charge les données par lots pour améliorer les performances.

Schema Flexibility
= Conserve les colonnes supplémentaires dans extra_data JSONB.

Validation
= Contrôle existence, taille, extension, colonnes et structure CSV.

Exception Handling
= Gère les erreurs de lecture, validation et chargement.
