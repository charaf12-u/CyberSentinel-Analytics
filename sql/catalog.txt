2. DATABASE SCHEMAS

bronze
= Stocke les données brutes provenant des collecteurs.

silver
= Contient les données nettoyées, typées, validées et dédupliquées par dbt.

intermediate
= Contient les transformations, enrichissements et corrélations intermédiaires.

warehouse
= Contient le modèle analytique final utilisé notamment par Power BI.

audit
= Stocke la traçabilité des chargements et du pipeline.

ml
= Stocke les résultats, scores et métadonnées Machine Learning.


3. MAIN TABLES

4. TECHNOLOGIES / TECHNIQUES

PostgreSQL
= Système de gestion de la base de données CyberSentinel.

SQL DDL
= Crée et structure les schémas, tables, contraintes et index.

BEGIN / COMMIT
= Exécute les scripts dans des transactions.

IF NOT EXISTS
= Permet de rejouer les scripts sans recréer les objets existants.

PRIMARY KEY
= Garantit l’identification unique des enregistrements.

UNIQUE
= Empêche certaines duplications de données.

CHECK Constraints
= Contrôle les valeurs autorisées directement dans PostgreSQL.

IDENTITY
= Génère automatiquement les identifiants techniques des lignes.

JSONB
= Conserve les données supplémentaires non modélisées.

TIMESTAMPTZ
= Stocke les dates et heures avec gestion du fuseau horaire.

UUID
= Identifie de manière unique une exécution du modèle ML.

Indexes
= Accélèrent les recherches, filtres, joins et transformations.

Composite Index
= Optimise les recherches utilisant plusieurs colonnes.

Partial Index
= Indexe uniquement les lignes répondant à une condition précise.

SHA-256
= Identifie les fichiers sources pour la traçabilité et la déduplication.

UPSERT / ON CONFLICT
= Permet d’insérer ou mettre à jour un chargement déjà enregistré.

Audit Trail
= Assure la traçabilité des fichiers et des chargements.

Bronze Layer
= Conserve les données proches de leur format source.

Medallion Architecture
= Organise le traitement Bronze → Silver → Intermediate → Warehouse.

ML Result Storage
= Sépare les résultats Machine Learning des données analytiques classiques.
